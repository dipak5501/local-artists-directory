# Local Artists Directory

A web app for discovering local artists and their work.

## Trend

Artisanal and handmade goods are gaining popularity, with a focus on supporting local communities.

## Users

Art lovers,Local community members,Artists

## Setup

```bash
npm install
npm test
npm run build
npm start   # http://127.0.0.1:8787/
```

## Stop

Ctrl+C

## Self-adaptation

This app continuously learns from a **representative** public-web scan on the Mac Studio (not the entire internet).

**Latest:** Enhancing Local Artists Directory

By integrating real-time data and user feedback, the Local Artists Directory can offer more personalized recommendations and improve artist discoverability. Adding a feature for artists to upload their works directly will also enhance engagement.

See `learning/LATEST.json` and `public/insights.json`.
